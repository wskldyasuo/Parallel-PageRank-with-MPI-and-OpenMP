# Experiment results

- `local/`: the retained four-dataset Mac experiment, with one warm-up and five
  measured runs per data-set/configuration pair, plus its median-based figure.
- `vanda/raw/`: five measured runs per completed cluster configuration.
- `vanda/figures/`: figures generated by `02_vanda_experiments.ipynb`.
- `vanda/e3/`: independent H1/H2 load-balancing records, logs, and figures
  generated by `03_load_balancing_experiment.ipynb`.
- `vanda/phase/`: representative instrumented strong-scaling runs and phase
  breakdown figures generated by `04_phase_timing_experiment.ipynb`.
- `vanda/demand/`: controlled full-vector versus demand-driven exchange data,
  logs, and figures generated by `05_demand_exchange_experiment.ipynb`.
- `vanda/waterfall_uk/`: the controlled UK-2002 pipeline run used for the
  end-to-end optimization waterfall in the Discussion. Each stage has one
  warm-up and five measured repetitions on the same Vanda node allocation.
- Generated CSV/TSV files are ignored by Git; preserve final experiment records
  in the submission archive or a dedicated data repository.
- `scripts/run_all_modes.sh` can create additional local CSV records when a
  new local experiment is needed. Legacy `CSR1` rows contain the original
  metrics; `CSR2` additionally records the partition policy, static rank-load
  statistics, and update-time imbalance. `CSR3` adds rank-mean and rank-max
  local compute, `Allreduce`, and score-exchange timing. `CSR4` adds dependency
  construction, packing, demand volume and partners, exchange-state bytes, and
  peak resident memory.
